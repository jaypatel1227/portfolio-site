We got a bunch of new models recently! 

Neon is great (uncharacteristically) and astra feels like an old school gemini model.

What kind of horrors did astra go through? It's so bad at figuring out which instructions to listen to which don't matter. In our codebases, there are random things which nudge models in directions and they have never fooled opus or even 6 astra into behaving incorrectly. It's good to clean this up and good for the model to alert me but having some generic file which say "ask before pushing" should not make it ignore my prompt which includes "rebase and push". 

It's astonishing how bad astra feels to use interactively. Still seems like the top line capability is very high but I can't know since it never keep going long enough for me to test it. Seems like some kind of weird RL artifacts. Including all of the safety training they must be doing...

My guess is that they were seeing issues where the model overstepped the instructions so they have been heavily punishing it for going beyond the most restrictive version of each instruction in the context. Seems like they just needed to have base model bake more instead of taping on this workaround. 

Very curious what's causing OAI to have alignment problems whereas Ant doesn't seem to have any issues at all. Looping the transformer + Grug speak might be making it so hard for them to monitor that it's causing some runaway alignment issues?

Also, the internal model "bel?" seems like it's likely just that different to interact with. The top level capability seems insane but if it acts like 6.2 astra, I don't think it will take off. Would be so cool to have them RL it to behave like Neon. I think Neon behavior and astra capability would match claude models, too bad :(

I guess OAI is out of the game for like 4 months or 6 months maybe? Then again, no idea if they can quickly fix this stuff? The 5.5 -> 5.6 sol jump is kind of what they need here.
